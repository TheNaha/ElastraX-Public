## Critical Bugs

### BUG-005 — FlowHandler compounding interval timer
- **Severity**: High
- **Location**: `src/core/FlowHandler.ts:157-181` (before fix)
- **Evidence**: `_startPeriodicSessionCleanup` scheduled `globalThis.setInterval(cleanup, ...)` both inside `cleanup` and again at the end of the function. Every hourly run created another permanent interval, so timer count grew without bound. No `stop()`/clear path existed; `resetForTesting()` did not clear it.
- **Verification**: read the function; traced `initialize()` calls it once per process.
- **Fix**: removed the inner scheduling; store the single timer id in `sessionCleanupTimer`; clear it in `resetForTesting()`. (commit pending)

### BUG-006 — Telegram never grants native group-admin role
- **Severity**: High
- **Location**: `src/providers/telegram.ts:517-519` (before fix)
- **Evidence**: `AuthService.resolveRoles(..., false, ...)` hard-coded `isPlatformAdmin=false`; no `getChatMember` call anywhere in the file. WhatsApp and Discord derive platform admin; Telegram did not, so admin-gated tools were unusable in Telegram groups.
- **Verification**: grep for `getChatMember`/`administrator` in `telegram.ts` returned none.
- **Fix**: resolve platform admin via `bot.api.getChatMember(chatId, userId)` for group chats (creator/administrator) before `resolveRoles`. (commit pending)

### BUG-007 — WebhookServer.stop() dropped a promise
- **Severity**: Medium
- **Location**: `src/webhooks/WebhookServer.ts:635-636` (before fix)
- **Evidence**: `this.server.stop()` returns `Promise<void>` (Bun `serve().stop()`), but `stop(): void` ignored it, leaving a possible unhandled rejection. Caller `AppRuntime.stop()` invoked it synchronously.
- **Verification**: `node_modules/bun-types/serve.d.ts:1026`; grep callers.
- **Fix**: made `stop()` async, awaited `server.stop()` with try/catch; updated `AppRuntime` caller to await. (commit pending)

### BUG-008 — Swallowed errors at close/parse boundaries
- **Severity**: Low
- **Location**: `src/db/index.ts:145,152`; `src/db/backup.ts:93,226`; `src/tools/MediaBindTool.ts:378`; `src/utils/EmbeddingService.ts:73`; `src/utils/permissions.ts:134-135`
- **Evidence**: empty/`void error` catches with no log; metadata JSON parse and permission BigInt failures disappeared.
- **Fix**: replaced with scoped `logger.warn`/`logger.debug` calls. (commit pending)

## Integration Gaps

### INT-001 — ReloadPluginsTool permanently disabled
- **Severity**: Medium
- **Location**: `src/plugins/ReloadPluginsTool.ts:25`, `src/tools/BaseTool.ts:267-269`
- **Evidence**: `optIn=true` but `optInFlag` stayed `null`; `isEnabled()` returns `false` when `optIn && !optInFlag`. The tool reads `ENABLE_PLUGIN_RELOAD` itself, but that code path was unreachable. Operator-facing reload command was dead.
- **Fix**: set `override readonly optInFlag = 'ENABLE_PLUGIN_RELOAD'`. (commit pending)

### INT-002 — Discord admin detection duplicated and helper detached
- **Severity**: Low
- **Location**: `src/utils/permissions.ts` (removed `isDiscordGroupAdmin`), `src/providers/discord.ts:374-383`
- **Evidence**: exported `isDiscordGroupAdmin` had zero callers; Discord reimplemented the same check inline. Removed the unused helper; inline path retained (behavior unchanged). Flagged for future unification.

### INT-003 — Stale piracy env names in admin allowlist
- **Severity**: Low
- **Location**: `src/admin/data.ts:407`

- **Fix**: removed stale entries. (commit pending)
