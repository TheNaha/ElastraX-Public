## Duplication Found — Safe to Fix

### TD-x: Raw error-message extraction duplicated at 10 call sites — RESOLVED (this pass)

**Evidence:** `safeErrorMessage(error)` in `src/utils/errorUtils.ts:29` centralizes error-message extraction (`error instanceof Error ? error.message : String(error)`) **plus** control-char sanitization and a length cap. Ten call sites repeat only the raw extraction, bypassing sanitization (log/terminal injection risk via provider error strings) and the length cap:

| File | Line | Current | Replacement |
|---|---|---|---|
| `src/ai/client.ts` | 148, 337, 545 | `cause: error instanceof Error ? error.message : String(error)` | `cause: safeErrorMessage(error)` |
| `src/tools/registry.ts` | 375 | `` `Invalid ${command} arguments: ${error instanceof Error ? error.message : String(error)}` `` | `` `Invalid ${command} arguments: ${safeErrorMessage(error)}` `` |
| `src/messaging/InboxService.ts` | 142, 169 | `const message = error instanceof Error ? error.message : String(error);` then `.slice(0, 2_000)` | `const message = safeErrorMessage(error, 2_000);` |
| `src/messaging/OutboxService.ts` | 227, 312 | same as InboxService | `const message = safeErrorMessage(error, 2_000);` |
| `src/utils/HealthMonitor.ts` | 24 | `const errorMessage = error instanceof Error ? error.message : String(error);` | `const errorMessage = safeErrorMessage(error);` |
| `src/utils/FFmpegConverter.ts` | 105 | `const message = error instanceof Error ? error.message : String(error);` then `.slice(0, 1000)` | `const message = safeErrorMessage(error, 1000);` |

**Why safe:** `safeErrorMessage` is a strict superset of the raw extraction (adds control-char stripping via `stripControlChars` and a configurable cap). No public contract, no data-format change. Call sites that already slice to 2000/1000 keep that cap by passing it as `maxLength`; the now-redundant outer `.slice()` is left in place as a harmless no-op to keep the diff minimal.

**Fix:** Replace all 10 sites, adding the `safeErrorMessage` import where missing (`ai/client.ts`, `tools/registry.ts`, `messaging/InboxService.ts`, `messaging/OutboxService.ts`, `utils/FFmpegConverter.ts`; `HealthMonitor.ts` already imports `getErrorMessage` from the same module).
