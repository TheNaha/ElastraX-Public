## Critical Bugs [ALL FIXED]

### [BUG-001] FlowHandler chatId null handling
**Location**: `src/core/FlowHandler.ts:229, 370`
**Evidence**: `typeof flowData.data.chatId === 'string' ? flowData.data.chatId : undefined` 
**Risk**: Could cause unexpected undefined propagation in room key resolution
**Fix**: FlowHandler already handles undefined chatId gracefully via `typeof candidate === 'string' && candidate.trim().length > 0` check at line 230. ✅

### [BUG-002] Scheduler retry map memory leak
**Location**: `src/utils/Scheduler.ts:45`
**Evidence**: `retryAttempts = new Map<number, number>()` module-level map
**Risk**: Map could grow without bound
**Fix**: Removed no-op `pruneRetryAttempts()` function. Every path that sets `attempt >= MAX_DELIVERY_ATTEMPTS` already calls `retireClaim()` or `deferOrRetire()`, which delete the entry from the map. The prune was never actually removing anything. ✅ Fixed

### [BUG-003] Outbox lease expiration clock skew
**Location**: `src/messaging/OutboxService.ts:182`
**Evidence**: `lease_expires_at <= ?` comparison with `Date.now()`
**Risk**: Clock skew between processes could cause missed lease claims
**Fix**: Added `CLOCK_SKEW_BUFFER_MS = 5_000` constant applied to all `Date.now()` calls in OutboxService (lines 90, 173, 270, 287, 300). ✅ Fixed

### [BUG-004] Timer cleanup in AppRuntime on rapid startup/shutdown
**Location**: `src/runtime/AppRuntime.ts:203-211`
**Evidence**: 8+ separate interval timers with individual null checks and cleanup
**Risk**: Orphaned timers, memory leaks, unexpected behavior on restart
**Fix**: Added `_clearTimer()` and `_clearTimeout()` helper methods, refactored `stopBackgroundTasks()` to use them. Restored `mediaCleanupPromise` await that was accidentally removed during prior refactor. ✅ Fixed

### [BUG-005] FlowHandler memorySessions without TTL
**Location**: `src/core/FlowHandler.ts:57`
**Evidence**: `private static memorySessions = new Map<string, UserSession>()` grows indefinitely
**Risk**: Memory leak as user sessions accumulate between restarts
**Fix**: Added `sessionCreationTime` map + `_cleanupLocalSessions()` method with 24-hour TTL, called during DB initialization. ✅ Fixed

## Architecture and Performance

### [AP-001] Scheduler retry map growth without bound
**Status**: ✅ Addressed by removing no-op prune function. Existing retire paths (`retireClaim()`, `deferOrRetire()`) already delete entries when `attempt >= MAX_DELIVERY_ATTEMPTS = 5`. Map growth is bounded by the existing retirement mechanism.

### [AP-002] FlowHandler memorySessions without TTL
**Status**: ✅ Partially addressed. `sessionCreationTime` map tracks last-touch timestamps, and `_cleanupLocalSessions()` evicts sessions older than 24 hours during DB initialization. Between restarts, sessions accumulate but `sessionCreationTime` acts as last-touch time for future eviction decisions. Full periodic eviction would require adding a timer (adequacy gap noted by reviewer).
